## Plan court P3 — Bug API admin users (5 étapes)

1. **Diag confirmé sans repro** : le middleware ligne 103-105 (`if (!user) return redirectToLogin(req, pathname)`) **et** ligne 70-75 (cas env Supabase manquant) **renvoient un 307 vers `/login`** sur **toutes** les routes, y compris `/api/admin/*`. Le browser suit le redirect par défaut (`fetch` `redirect:'follow'`) et reçoit la page HTML `/login` → `JSON.parse` côté `InviteUserDialog`/`RegeneratePasswordButton` → `Unexpected token <`. **Hypothèse 1 du plan confirmée par lecture du code**. (Note : pour les autres causes de refus — domaine hors AlyoS, `must_change_password`, `forbidden_role` — le middleware renvoie déjà du JSON 403 propre. Le seul trou est le 401 / pas-de-session, qui retombe sur `redirectToLogin`.)

2. **Patch middleware** (`src/middleware.ts`) :
   - Ligne 70-75 (env manquant) → si `isProtectedApiRoute(pathname)`, renvoyer `NextResponse.json({error:'service_unavailable', ...}, {status:503})` au lieu de `redirectToLogin`.
   - Ligne 103-105 (session absente) → si `isProtectedApiRoute(pathname)`, renvoyer `NextResponse.json({error:'unauthorized', message:'Authentification requise.'}, {status:401})` au lieu de `redirectToLogin`.
   - Catch global ligne 209-216 → idem, si API route, renvoyer JSON 500 au lieu de redirect.

3. **Patch UI consommateurs** (`InviteUserDialog.tsx`, `RegeneratePasswordButton.tsx`) :
   - Sur `resp.status === 401`, afficher un message « Session expirée — veuillez vous reconnecter. » + `window.location.href = '/login?next=' + encodeURIComponent(location.pathname)`. Pas de toast système (pas dispo MVP), on garde l'état d'erreur inline existant + redirect.

4. **Test unit Vitest** (à ajouter côté `tests/unit/middleware/...`) : couvrir « API route sans session → JSON 401 (pas redirect HTML) ». Mock minimal de `createServerClient` qui renvoie `{user:null}`. Je crée le squelette et laisse à Camille le E2E Playwright (parcours `/api/admin/users` sans cookie → 401 JSON ; UI consommateur affiche message session expirée).

5. **E2E Playwright pour Camille (qa)** — un nouveau fichier `e2e/admin-users-session-expired.spec.ts` à scaffolder :
   - C1 : `request.post('/api/admin/users', {data:{...}})` sans cookie → `expect(r.status()).toBe(401)` + body JSON `{error:'unauthorized'}`.
   - C2 : connecté puis cookies `sb-*` supprimés → `InviteUserDialog` submit → vérifie redirect `/login?next=/sourcing/admin/users`.
