   téléchargés** à cette étape (lourd, à faire étape 3).

2. **Lib auth pure** :
   - `src/lib/auth/domain.ts` : `isAuthorizedEmail(email)` avec normalisation
     lowercase + match strict `endsWith("@alyosingenierie.fr")` + garde-fou
     double `@` (défense en profondeur contre `bob@evil@alyosingenierie.fr`).
   - `src/lib/auth/routes.ts` : constantes `PUBLIC_ROUTES`, `PROTECTED_PREFIX`,
     `PROTECTED_API_PREFIX` + helpers `isPublicRoute`/`isProtectedUiRoute`/
     `isProtectedApiRoute`.
   - **49 tests Vitest verts, coverage 100 %** sur `src/lib/auth/**` (seuil
     Gate 5 = 90 %). Matrice C3, C4, C10, C11, C12 + 10 edge cases (null,
     undefined, empty, whitespace, alias `+`, double `@`, sans `@`).

3. **`middleware.ts` racine** : implémentation complète du skeleton §3.1 spec.
   - Matcher exclut `_next/static`, `_next/image`, `favicon.ico`, assets
     (`svg`, `png`, `jpg`, `jpeg`, `gif`, `webp`, `woff`, `woff2`, `ico`).
   - Routes publiques → `NextResponse.next()`.
   - Routes non protégées non publiques → `NextResponse.next()` (laissé passer).
   - Routes protégées sans env Supabase → redirect `/login` (fallback dev).
   - Routes protégées + pas de session → redirect `/login?next=<path>` (C2/C8/C9).
   - Routes protégées + email Alyos → laisser passer + audit log succès (C3/C6).
   - Routes protégées + email hors domaine → `signOut()` + 403 :
     - UI → redirect `/forbidden` (C4).
     - API → JSON `{"error":"forbidden_domain"}` (C7).
   - `extractClientIp()` : `x-forwarded-for` premier hop puis `req.ip`.
   - `logAccessAttempt()` stubé en `console.warn` (TODO étape 7 quand
     `audit_logs` existera en BDD).
