🐳3. Fly.io — Configuration v2 (mise à jour)

⚠️ Mise à jour vs v1.0
La v1.0 estimait 5 €/mois pour un container 256 Mo always-on. La configuration réelle est différente : shared-cpu-2x · 2 GB RAM · auto-stop pour supporter Playwright (Chromium), les scrapers PLACE + Francmarchés simultanément, et les pages JS lourdes. Le auto_stop_machines = "stop" ramène le coût réel à 3–8 €/mois selon la fréquence des scrapes.
Paramètre Valeur Justification
Machine shared-cpu-2x Chromium headless + 2 scrapers en parallèle nécessitent > 1 vCPU
RAM 2 048 MB Playwright peak ~800–1 200 MB par browser context actif
Région cdg (Paris) Latence minimale vers sites FR (PLACE, Francmarchés) + conformité UE
Auto-stop auto_stop_machines = "stop" Machine arrêtée ~5 min après le dernier job — économie ~60 % vs always-on
Auto-start auto_start_machines = true Démarrage automatique à chaque POST /v1/scrape (cold start ~8–12 s)
Fréquence scraping 2 × /jour (cron 04:30 UTC) × 2 plateformes × 1 profil ~4 jobs/jour, ~20–60 min cumul actif/jour
Coût estimé 3–8 € HT/mois Fly.io Machines billing: $0.00000225/vCPU/s + $0.0000035/MB/s
