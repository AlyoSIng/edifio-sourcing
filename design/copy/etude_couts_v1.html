Conclusions clés

  1. La structure de coûts est saine. Les coûts variables par client représentent 8-12 % du tarif perçu selon le palier. La marge contributive est donc > 88 % avant coûts fixes.
  2. Les coûts fixes (équipe) dominent largement les 12-24 premiers mois. Ils représentent ~90 % de la facture mensuelle à 50 clients, mais < 50 % à 300 clients (scale).
  3. Le poste Anthropic API est le seul vraiment volatil sur les coûts variables. À 100 clients, il représente ~40 % des coûts variables (mais 6-8 % du CA).
  4. 21 leviers identifiés, dont 6 « quick wins » à impact > 5 k€/an chacun activables en < 1 mois d'effort.
  5. L'EBITDA An 5 peut passer de 451 k€ à 566 k€ (+25 %) si tous les leviers sont actionnés sans dégrader la qualité produit.

7. 21 leviers d'optimisation

Chaque levier est étiqueté T (Technique), F (Fonctionnel) ou M (Managérial), avec impact chiffré (€/an économisés à 200 clients actifs) et effort de mise en œuvre.

7.1. Leviers techniques (T1 à T8) — pilotés par CTO Sophie

T1Cache des appels Anthropic Haiku (scoring AO)~9 k€/an
Beaucoup d'AO réapparaissent à l'identique sur plusieurs plateformes (BOAMP + MP.info publient souvent le même AO). Mettre en place un cache 7 jours sur le hash composite (CPV + acheteur + objet) → réduction ~35 % des appels Haiku scoring. À 200 clients qui consomment ~10 € de Haiku/mo → économie 35 % × 10 € × 200 × 12 = 8 400 €/an.
Effort : 2-3 j Alex · Tech : table cache Drizzle + TTL côté Edge Function
T2Prompt caching Anthropic (system prompts répétés)~14 k€/an
L'API Anthropic supporte le prompt caching depuis 2024. Les system prompts P1 (analyse RC) et P2 (mémoire technique) sont identiques entre appels, seul l'input client change. Activer le caching → réduction ~70 % du coût des tokens input répétés. Sur le tier Studio IA (60 €/client/mo de Sonnet), économie ~14 % du tier → 14 €/client/mo × 45 clients Studio × 12 = 7 560 €/an. Avec montée en volume, ~14 k€/an à terme.
Effort : 1-2 j Alex · Tech : ajout headers cache-control sur appels Anthropic
T3Compression jsonb agressive (raw_data BOAMP)~3 k€/an
Postgres supporte la compression TOAST automatiquement, mais on peut forcer une compression LZ4 sur les colonnes jsonb les plus volumineuses (`tenders.raw_data`, `ai_runs.output`). Réduction storage ~4×. Sur 200 clients × 2 Go × 0,021 €/Go/mo Supabase = 8,4 €/client/mo → -75 % = 6,3 €/client/mo économisés × 200 × 12 = 15 120 €/an théorique. En pratique, hit ~20 % du total storage → 3 k€/an réaliste.
Effort : 1 j Alex (ALTER TABLE SET STORAGE EXTERNAL/EXTENDED)
T4CDN Vercel pour assets statiques (PDFs générés, images)~2 k€/an
Les PDFs générés du module IA dossier (CERFA + mémoire technique) sont servis directement depuis Supabase storage → bandwidth Supabase consommé. Servir via CDN Vercel (inclus dans le plan Pro) → bandwidth gratuit pour ces assets. Économie ~30 % du bandwidth Supabase total → 2 k€/an à 200 clients.
Effort : 3-5 j Alex · Tech : signed URLs courte durée Supabase + Vercel Edge proxy
T5Edge Functions Deno partout possible (vs Vercel Node functions)~1,5 k€/an
Les Edge Functions Supabase Deno sont gratuites jusqu'à 2 M invocations/mo. Les Vercel Functions Node payantes au-delà du quota Pro. Migrer le cron scoring + webhooks Brevo + endpoints publics tokenisés vers Edge → économie GB-hours Vercel.
Effort : 5-8 j Alex (migration code Node → Deno + tests E2E) · Décision ORM Drizzle déjà compatible Deno
T6Optimisation prompts Anthropic (Sonnet → Haiku là où possible)~6 k€/an
Audit régulier des 12 prompts versionés `ai_prompts_v1.md`. P10 library_piece_match et P12 accroche_memo_intro pourraient passer Sonnet → Haiku si tests qualité restent acceptables. Haiku ~10× moins cher. Économie ciblée P10 (200 calls/mo × 0,02 € → 0,002 €) sur 200 clients × 12 = 864 €/an. P3 CERFA pourrait aussi être migrée si on accepte une review humaine systématique. Économie cumulée ~6 k€/an.
Effort : 5-10 j Alex (A/B tests Sonnet vs Haiku sur chaque prompt + grille qualité)
T7Drizzle batch upsert (déjà acté ADR-013)~1 k€/an
Décision ORM 2026-05-18 (ADR-013) : Drizzle batch upsert via `onConflictDoUpdate` réduit le nombre de connexions Postgres (1 connexion pour 100 lignes vs 100 connexions). Conséquence : moins de compute Supabase consommé → palier Supabase Team retardé de 3-6 mois. Économie marginale ~1 k€/an mais effort déjà absorbé.
Effort : déjà fait (ADR-013, bench Phase 2a) — Pas d'action additionnelle
T8Self-hosting scraping (Fly.io → VPS OVH dédié)~0,3 k€/an
Au-delà de 100 clients, Fly.io scale à 3 instances ~20 €/mo. Un VPS OVH 4 Go RAM coûte ~7-10 €/mo et peut héberger les 3 jobs scraping en parallèle. Économie ~10-15 €/mo. Mais perte de la geo-distribution Fly.io. À envisager seulement si on confirme que le scraping n'a pas besoin de hop EU multi-zone.
Effort : 3-5 j Yann (provisioning VPS + scripts cron + monitoring) · ROI faible → optionnel

7.2. Leviers fonctionnels (F1 à F7) — pilotés par CMO Léa

F1Quota dur Studio IA 20 AO/mois + overage 1,50 €/AO (déjà acté Gate 1)~13 k€/an
Les clients gros consommateurs Studio IA (5 % des Studio qui font > 20 AO/mois) paient l'overage à coût direct. Évite la concentration des pertes. Hypothèse : 10 % des clients Studio dépassent en moyenne de 8 AO/mois → 8 × 1,50 € × 4,5 clients × 12 = 648 €/an facturation directe. Plus important : effet dissuasif sur la sur-consommation IA non rentable → ~13 k€/an d'économie indirecte (sans le quota, certains clients consommeraient ×3 leur tier).
Effort : déjà spec'd · Implémentation au module IA dossier (1-2 j compteur + paywall soft)
F2Engagement annuel -15 % (vs mensuel)~4 k€/an + cash flow
Proposer paiement annuel upfront avec remise -15 %. Cible : 30 % des clients optent pour l'annuel. Impact : meilleur cash flow (1 an de revenu upfront), churn réduit (engagement). Économie indirecte via réduction churn : si 30 % des clients passent de churn 15 % à churn 5 % → ~10 % de revenu préservé sur ces clients. À 200 clients × 30 % × 350 € × 12 × 10 % = 25 k€ revenu préservé. Mais coût de la remise = 15 % × 30 % × 200 × 350 × 12 = 38 k€. **Net : -13 k€/an direct mais cash flow +30 mois × 350 × 60 × 0,85 = 535 k€** mobilisable. Économie indirecte rétention : ~4 k€/an net.
Effort : 2-3 j Alex (Stripe annual billing + UI tarification) · 1 j Léa (page tarification)
F3Tier intermédiaire « Sourcing+ » à 290 €/mo~22 k€/an
Ajouter un tier entre Sourcing (190 €) et Cotraitance (390 €) avec : Sourcing + scoring IA Haiku enrichi + 1 sollicitation Tandem/mois incluse. Capture la zone de transition d'upsell naturelle. Hypothèse : 25 % des clients Sourcing migrent vers Sourcing+ (+100 €/mo) au lieu de stagner. Gain : 0,5 × 100 € × 25 % × 200 × 12 = 30 k€/an. Coût de complexification produit : ~8 k€/an (support, marketing). **Net : ~22 k€/an.**
Effort : 5-7 j Alex (logique feature flag + facturation) · 2 j Léa (positionnement + page tarif)
F4Self-serve onboarding (suppression du demo call obligatoire)~18 k€/an
Coût actuel demo call obligatoire = 30-45 min CS par lead × 30 % conversion = ~1,5h CS par client converti × 50 €/h coût chargé = 75 € par client converti. Sur 100 nouveaux clients/an → 7,5 k€. Économie en passant au self-serve (avec demo en option) : -70 % de ces coûts + augmentation conversion lead → client de +20 % par friction réduite. Net : ~18 k€/an.
Effort : 5-8 j Alex (signup flow + tutoriel intégré) · 3 j Léa (Loom vidéos × 5 + emails onboarding) · 2 j Théo (UX onboarding)
F5Marketplace templates mémoires techniques (revenus secondaires)~6 k€/an
Les clients Studio IA produisent des mémoires techniques par CPV. Proposer un marketplace anonymisé où ils peuvent vendre/partager des templates contre crédits AO Studio. Sources de revenus marketplace : 20 % de commission sur 50 transactions/an × 50 €/template = 500 € direct. Mais surtout : effet réseau, fidélisation +30 % sur les clients Studio engagés dans le marketplace. Économie churn équivalente : ~6 k€/an.
Effort : 10-15 j Alex (UI marketplace + paiement crédits) · Effort élevé → Year 3
F6Surcharge module Tandem au-delà de 10 sollicitations/mois~3 k€/an
Cotraitance inclut sollicitations illimitées. Mais le coût Brevo + Anthropic Haiku matching scale linéairement. Ajouter un quota soft 10 sollicitations/mois inclus + 1 €/sollicitation supplémentaire. Hypothèse : 15 % des clients Cotraitance dépassent en moyenne de 5/mois → 5 × 1 € × 10 clients × 12 = 600 €/an direct. Effet de modération : -20 % du volume Brevo sur les usages abusifs → 2,4 k€/an indirect.
Effort : 1-2 j Alex (compteur + paywall) · Communication onboarding
F7Push upsell automatique vers Cotraitance dès mois 4 d'usage Sourcing~28 k€/an
Quand un client Sourcing a utilisé l'app activement pendant 4 mois et a regardé la fiche Tandem au moins 3 fois sans conversion, déclencher un push automatique « Essayez Cotraitance pendant 30 jours offerts ». Hypothèse : conversion 25 % des Sourcing actifs après 4 mois → +200 €/mo × 25 % × 75 clients ciblés × 9 mois moyen × = 28 k€/an de revenus additionnels. Coût d'opportunité : 25 clients × 30 j × 200 € / 30 = ~5 k€ de gratuité offerte. **Net : ~23 k€/an de revenu net additionnel.**
Effort : 4-6 j Alex (event-based push + tracking analytics) · 2 j Léa (séquence email + page d'atterrissage)

7.3. Leviers managériaux (M1 à M6) — pilotés par CEO Marc

M1Équipe lean : pas d'embauche avant 100 clients~55 k€/an
Ne pas embaucher de CS dédié avant 100 clients (Alex + Yann + Sophie absorbent le support occasionnel via canaux Slack/email). Tenue à 4 ETP max jusqu'au seuil 100 clients. Économie 1 ETP CS junior pendant 12-18 mois = 35-55 k€/an retardés.
Effort : zéro (décision RH) · Risque : surchargement Sophie/Alex sur Q2-Q3 An 2
M2Outsourcing support N1 (plateforme externe FR)~15 k€/an
À 100+ clients, plutôt qu'embaucher un CS 0,5 ETP (~25 k€/an chargé), externaliser le support N1 à une plateforme spécialisée SaaS BTP type Effisens / Webhelp SaaS. Tarif ~200-400 €/mois pour 50-100 tickets/mois traités. Économie ~15 k€/an + flexibilité.
Effort : 5-10 j sourcing + onboarding partenaire · Risque : qualité réponse N1
M3Acquisition via partenariats fédérations BTP (FFB / CAPEB / FNTP)~30 k€/an
Négocier avec la FFB Île-de-France et la CAPEB un partenariat « tarif adhérent -10 % » contre référencement dans leur catalogue d'outils recommandés. CAC quasi nul sur ces leads (vs 600 € moyen). Hypothèse : 30 leads/an via fédérations × 600 € de CAC évité = 18 k€/an. Plus signature crédibilité = conversion ×2 = ~30 k€/an effet cumulé.
Effort : 10-15 j Marc + Léa (négociation, présentation, contractualisation) · ROI exceptionnel
M4Programme ambassadeurs early adopters (3 mois gratuits par parrainage)~20 k€/an
Les 10 clients pilotes AlyoS reçoivent 3 mois gratuits pour chaque nouveau client converti via leur référencement. Hypothèse : 5 conversions de parrainage/an × 350 € × 3 mois = 5,2 k€ de coût programme. En contrepartie : 20-25 nouveaux clients/an × 600 € CAC évité = 13 k€ + crédibilité témoignage = effet rétention ~7 k€. **Net : ~20 k€/an.**
Effort : 3 j Léa (programme + landing + tracking) · 1 j Alex (codes referral)
M5Revue trimestrielle coûts par catégorie + alertes seuils~8 k€/an (effet cumulé)
Mettre en place une dashboard dédiée + alertes Slack à 80 % et 100 % des seuils budgétaires pour Anthropic / Supabase / Vercel / Brevo / Resend. Revue trimestrielle CEO + CTO : identification anomalies + optimisations ad hoc. Hypothèse : détection rapide de 2-3 anomalies/an évitant des dépassements ~3-4 k€ chacun = 8 k€/an de fuite évitée.
Effort : 2-3 j Alex (dashboard Grafana / Metabase + alertes Sentry) · 1 j Marc pilotage
M6Réseau ambassadeurs verticalisé (CHR, scolaire, voirie)~18 k€/an
À partir d'An 2, identifier 3 verticales BTP haute fréquence d'AO (CHR=café-hôtellerie-restauration, équipements scolaires, voirie). Recruter 1 ambassadeur expert par verticale (consultant 1 j/mois rémunéré 500 €). Acquisition ciblée via leur réseau professionnel + conférences. CAC très faible (référencement direct). Hypothèse : 15-20 leads/an par verticale × 3 verticales = 50 leads × 30 % conversion × 350 € × 24 mois moyenne = 126 k€ revenus, coût 18 k€/an, **net ~18 k€/an.**
Effort : 5-10 j Léa par verticale (recrutement + onboarding ambassadeur) · ROI à partir d'An 2

9.2. Risques d'optimisation excessive

Trois pièges à éviter

  1. Sur-engineering des leviers techniques au détriment de la rapidité de release MVP. T5 (Edge Functions) et T8 (self-hosting) peuvent attendre An 2-3 sans pénaliser le business.
