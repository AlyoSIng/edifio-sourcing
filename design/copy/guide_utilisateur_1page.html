Mode Solo vs Tandem — quand choisir quoi ?

🧍
Solo
Vous répondez en propre, en mandataire seul. L'AO bascule en pipeline et l'opportunité est créée dans Odoo.
Quand : marché de travaux pur, montant maîtrisé, équipe interne complète.
🤝
Tandem
Vous mobilisez un architecte cotraitant. edifio Sourcing propose 3 architectes scorés et envoie la sollicitation par mail.
Quand : MOE requise, ERP, marché complexe, expertise pointue nécessaire.

Préparation du dossier IA — 4 étapes

1 Upload DCE Glissez le RC, CCAP, CCTP, plans dans la fiche AO.
2 Préparer auto Tap le bouton « Préparer ». L'IA analyse en 30 secondes.
3 Reviser Side-by-side. Validez chaque pièce. Retouchez si besoin.
4 Diffuser Compilation ZIP envoyée à l'architecte via lien sécurisé.

Statuts d'un AO — la vie complète

Sourcé → Sélectionné (Solo / Tandem) → Architecte sollicité → Architecte OK → Dossier en préparation → Dossier prêt → Dossier diffusé → Remis → Gagné / Perdu / Sans suite

Les statuts s'affichent en couleur dans le Kanban. Le système trace toutes les transitions dans la timeline de la fiche.

Bonnes pratiques

⚠ Validez TOUJOURS l'IA

L'IA peut se tromper. Lisez chaque pièce, chaque ligne du mémoire. Vous êtes responsable du pli signé.

📚 Tenez la bibliothèque à jour

Attestations expirées = pli rejetable. L'app vous alerte J-30 / J-7 / J-1.

👋 Tutoiement par défaut

Les architectes que vous ne connaissez pas reçoivent un mail vouvoyé. Le tutoiement se gagne — vous pouvez le modifier dans leur fiche.

📲 Installez la PWA

iPhone : bouton Partager → « Sur l'écran d'accueil ». Android : « Installer l'application ». Vous gagnez les notifs push.
