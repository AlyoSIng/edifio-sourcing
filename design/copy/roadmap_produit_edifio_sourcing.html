edifio Sourcing — Roadmap

Vue Now / Next / Later · MAJ 2026-05-27 · Statut : MVP (Gate 6) en production interne AlyoS.

Now — livré / en cours

  • ✓ Détection quotidienne des AO (source BOAMP) + scoring de pertinence.
  • ✓ AO du jour : file priorisée, report / écartement des annonces non traitées.
  • ✓ Trois façons de répondre : Mandataire, Cotraitance (shortlist d'architectes scorés, scoring géo départemental + effectif cabinet) et Conception-Réalisation (groupement MOE + réalisateur).
  • ✓ Bibliothèque cotraitants + coffre documentaire BET (12 pièces, alertes d'expiration).
  • ✓ CRM Contacts : Architectes / Bureaux d'Études / Entreprises-Majors + enrichissement Pappers.
  • ✓ Espace utilisateur : actualités, support, formations, tests guidés, FAQ, démo.
  • ✓ Console superadmin : support, tests guidés, news, plaquette, roadmap, étude de marché.
  • ⏳ AO par département : affichage du code postal + tri / filtre par département et jours avant clôture.
  • ⏳ Brief d'opportunité IA et contenu d'onboarding (vidéo démo, formations, FAQ).

Next — prochaines semaines

  • Durcissement sécurité : RLS FORCE sur l'ensemble des tables, audit trail complet (RGPD).
  • Observabilité : alertes sur la collecte automatique (échec / 0 annonce) et monitoring.
  • Sources élargies : connecteurs PLACE et Francmarchés en complément du BOAMP.
  • Règlement de consultation (RC) isolé et extraction des pièces du DCE.
  • Finalisation UI alignée sur le design system edifio.

Later — Phase 2

  • Ouverture commerciale multi-tenant (clients externes), facturation.
  • Console « edifio Admin » unifiée Sourcing + Suivi (vue client 360°, base contacts partagée).
  • Flywheel cross-app : passerelles de prospects entre edifio Sourcing, Suivi et ACT.
  • Multi-cotraitants par appel d'offres (au-delà d'un cotraitant unique).
  • Export PDF des shortlists et dossiers de candidature.
  • Studio IA avancé : aide à la rédaction du mémoire technique.
Roadmap indicative — édité par AlyoS Ingénierie. Les priorités « Next » et « Later » peuvent évoluer selon les retours d'usage et les décisions du Board. v1 — 2026-05-27.
